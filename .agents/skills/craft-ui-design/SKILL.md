# Craft UI Design System (Anti-AI Aesthetic & Pro-Workstation)

Данный скилл определяет строгие принципы проектирования современных цифровых продуктов профессионального уровня (уровень Ableton, Linear, Raycast, Teenage Engineering, Apple HIG), полностью исключающие узнаваемый дешевый вид «сгенерировано ИИ».

---

## 🚫 1. Главные маркеры "AI-дизайна" (Чего категорически избегать)

1. **Радужные градиенты и неоновое свечение (Glow/Blur abuse):**
   - ❌ Градиентные радужные кнопки `bg-gradient-to-r from-blue-500 via-indigo-500 to-purple-600`.
   - ❌ Цветные размытые пятна в фоне (`blur-3xl bg-purple-500/30`).
   - ❌ Неоновые светящиеся бордеры без функционального смысла.
2. **Шаблонный дашборд с 6 одинаковыми карточками метрик:**
   - ❌ Бессмысленные квадраты с огромными белыми цифрами 36px и блеклой подписью вверху.
3. **Конфетти из круглых цветных пилюль (Badge abuse):**
   - ❌ В каждой строке таблицы висит по 3 разноцветных ярких овала (зеленый, фиолетовый, синий, красный).
4. **Рыхлые отступы и отсутствие плотности:**
   - ❌ Огромные пустоты `p-8`, `gap-8`, из-за которых на экране умещается всего 3 строчки полезных данных.
5. **Игрушечные иконки и эмодзи в заголовках:**
   - ❌ Использование смайликов 🚀, ⚡, 🎉 в кнопках и меню профессиональных утилит.

## ✨ 2. Принципы Pro-Workstation UI (Как делать красиво и зрело)

### А. Палитра и материалы (Obsidian & Deep Titanium)
- **Фон:** Глубокий матовый обсидиан `#080a0f` / `#0d1117`, а не сине-фиолетовый `slate-900`.
- **Поверхности (Слои):**
  - Base: `#0a0d13`
  - Elevated Surface (рэк, панели): `#12161f`
  - Card / Section: `#161b26`
  - Active / Hover: `#1c2331`
- **Границы и разделители:**
  - Субтильные, микроскопические границы: `rgba(255, 255, 255, 0.08)` или `#222938`.
  - Внутренний блик (inset highlight): `box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.05)` — создает эффект настоящей физической фрезерованной панели.
- **Акценты (Студийный свет):**
  - **Studio Amber / Vintage VU:** `#f59e0b` / теплый ламповый оранжевый `#fb923c` — акцент студийных индикаторов.
  - **Signal Emerald:** `#10b981` — активный статус, четкие точечные светодиоды (LED 6px), а не огромные плашки.
  - **Ice Cyan / Accent Blue:** `#38bdf8` / `#2563eb` — строгий фокус и выбранные элементы.

### Б. Профессиональная типографика и сетка
- **Шрифты:** Системный стек Apple (`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text"`) для интерфейса + `JetBrains Mono` / `SF Mono` для таймкодов, частот, путей и тегов.
- **Табличные цифры:** Обязательный класс `tabular-nums` / `font-variant-numeric: tabular-nums` для таймкодов `[00:14.20]`, битрейта, счетчиков и таймеров, чтобы цифры не прыгали.
- **Горячие клавиши (Kbd):** Компактные визуальные подсказки `⌘1`, `⌘2`, `Space`, `Esc` с окантовкой.

### В. Архитектура рабочих экранов (Audio Studio Ergonomics)
1. **Header Bar:**
   - Компактная консоль: статус реверс-прокси, аптайм, активный энвайронмент, текущий мастер-воркер.
2. **Сегментированное переключение режимов:**
   - Металлический segmented control (как в macOS / Logic Pro), тактильное ощущение переключения.
3. **Staging Рефакторинг (Audio Tag Diff Inspector):**
   - Инспекция в стиле кассет/треков: слева оригинал со стертыми или битыми тегами, справа — хирургически выверенные метаданные Picard, стрелка перехода, статус контрольной суммы FLAC MD5 Bit-Perfect.
   - Кнопка отката `Undo` рядом с историей примененных правок.
4. **LRC Teleprompter Studio:**
   - Двухпанельный пульт: слева плотный список треков с миниатюрами обложек и индикатором качества текста.
   - Справа: интерактивный телесуфлер с бегущей строкой таймкодов, быстрым переключением между сырыми ответами 5 баз, точным микро-сдвигом миллисекунд и кнопкой сохранения.
5. **Key Pool Hardware Rack:**
   - Визуализация в виде аппаратного рэкового модуля: слоты для каждого ключа со светодиодным индикатором питания (Active/Cooldown/Exhausted), живая шкала квоты и таймер обратного отсчета до сброса лимита.
