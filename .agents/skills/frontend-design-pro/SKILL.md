# Frontend Design Pro System (Linear, Raycast & Apple Music Standard)

Данный регламент определяет стандарты фронтенд-инженерии и визуального дизайна уровня Linear, Raycast, Apple Music и Vercel. Он полностью исключает узнаваемые шаблоны нейросетей и обеспечивает премиальный, выверенный опыт.

---

## 🚫 1. Анти-паттерны ("AI Slop" — что немедленно выдает ИИ)

1. **Шаблонный блок из 6 одинаковых карточек метрик:**
   - Категорически запрещено начинать интерфейс с сетки одинаковых бессмысленных плиток с огромными цифрами.
   - Вместо этого: **Interactive Status Bar / Filter Hub** с живыми фильтрами, индикатором общей целостности медиатеки (%) и контекстными действиями.
2. **Конфетти из разноцветных овальных бейджей:**
   - Запрещено вешать на каждую строчку по 3-4 разноцветных пилюли (зеленую, красную, фиолетовую, синюю).
   - Статус должен выражаться минималистичными светодиодными точками (LED 6px), изящной моноширинной типографикой или субтильным цветом текста.
3. **Радужные градиенты и неоновые пятна размытия (Glow / Blur abuse):**
   - Запрещены градиенты `from-blue-500 via-purple-500 to-pink-500` на кнопках и логотипах.
   - Дизайн должен строиться на контрасте глубоких нейтральных материалов (Obsidian / Zinc / Titanium), тонких микро-гранях (1px borders `rgba(255,255,255,0.08)`) и внутреннем блике (`inset 0 1px 0 rgba(255,255,255,0.08)`).
4. **Скучные сырые текстовые поля ввода:**
   - В музыкальных сервисах текст песен нельзя показывать просто в сером прямоугольнике `<textarea>`.
   - Должен быть полноценный **Karaoke Teleprompter** (как в Apple Music и Spotify) с крупной типографикой, подсветкой активной строки, размытием соседних строк и интерактивным переходом по клику.
5. **Отсутствие обложек в музыкальном приложении:**
   - Музыкальный софт без красивых обложек выглядит безжизненно. Обложки должны быть акцентом: скругление, виниловый отблеск, бейдж разрешения (`3000x3000`, `FLAC Bit-Perfect`).

## 💎 2. Архитектура экранов Pro-уровня

### 1. Command Bar (`⌘K`) и Хедер
- Интегрированная строка быстрого поиска и переключения контекста в стиле Raycast.
- Индикаторы состояния: аптайм, порт `:4534` (онлайн), активный воркер, домен `teedi.ru`.

### 2. Мультимедийный Staging-инспектор (Diff View)
- Карточки релизов с отображением обложек альбомов.
- Наглядное сравнение старых и новых тегов: красное перечеркивание кракозябр `Êèíî` -> чистый изумрудный `Кино` (NFC).
- Бейдж валидации целостности: `FLAC STREAMINFO MD5 Bit-Perfect ✓`.
- Плавающий action-бар для быстрого применения или отката (Undo).

### 3. Apple Music-Style Live Karaoke Teleprompter
- Два режима:
  - **Live Teleprompter**: крупный шрифт (20-24px), плавная прокрутка, активная строка подсвечивается ярким белым цветом с мягкой тенью, соседние строки плавно полупрозрачны (opacity 40%).
  - **Raw LRC Editor**: переключение в точный редактор таймкодов со сдвигом миллисекунд и валидацией синтаксиса.
- Слайдер / прогресс-бар трека с симуляцией воспроизведения и синхронизации.
- Переключение между 5 провайдерами из `provider_cache` в виде компактных сегментов.

### 4. Аппаратный рэк API-ключей (Hardware Unit)
- Аппаратный вид ячеек с LED-светодиодами состояния.
- Живые таймеры обратного отсчета Cooldown (65s) и индикаторы дневных лимитов до 11:00 МСК.
