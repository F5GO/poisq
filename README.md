# poisq (v0.2.0) — Умный AI-комбайн для медиатеки и Subsonic-прокси

**poisq** — это высокопроизводительный микросервис на Go для музыкального сервера [Navidrome](https://www.navidrome.org/), объединяющий сверхбыстрый умный Subsonic-поиск, бережный AI-рефакторинг тегов по стандарту **MusicBrainz Picard**, каскадный поиск текстов песен (**LRC Tournament** по 4 базам с умным поиском и сверкой текстов), генерацию караоке (**Groq Whisper + Gemini 2.5 Flash**) и встроенную веб-админку.

Работает на проде **[teedi.ru](https://teedi.ru)** и в локальных медиатеках.

---

## 🎯 Главные возможности

### 1. Умный и нечеткий поиск (Публичный порт `:4534`)
- **Забыли переключить раскладку:** найдет *Nirvana* по запросу `Тшкмфтф` или *Кино* по запросу `rbyj`.
- **Написали по-русски на слух:** поймет `офспринг` как *The Offspring*, а `металика` как *Metallica*.
- **Опечатались:** исправит случайные ошибки вроде `щеаызкштп` или `splean` на лету.
- **Мгновенный автокомплит с 1–2 букв:** подскажет исполнителя сразу (например, `оф` -> *The Offspring*).
- **Чистый прокси:** публичный порт `:4534` не перегружен лишней логикой — тексты песен клиентам отдает сам Navidrome, нативно подтягивая файлы `<filename>.lrc` из папки с треком.

### 2. Бережный Staging-рефакторинг тегов и защита медиатеки (Порт `:4535`)
- **Принцип Staging (Никакой слепой перезаписи):** сканер никогда не переименовывает файлы и не перезаписывает теги вслепую. Все предложения складываются в базу `poisq.db`, а решение принимает пользователь в веб-интерфейсе одной кнопкой.
- **Откат в один клик (Undo):** перед любым изменением сервис сохраняет полный JSON-слепок исходных тегов файла. Любую правку можно мгновенно откатить.
- **Стандарт MusicBrainz Picard (Bit-Perfect Audio):**
  - Аудиопоток никогда не перекодируется (`ffmpeg -map 0 -c copy -map_metadata 0`).
  - Для FLAC проводится обязательная сверка 16-байтной контрольной суммы `STREAMINFO MD5` нежатого звука до и после записи тегов. Если сумма не совпала — файл не трогается.
  - Сохраняются все существующие технические и пользовательские теги (`REPLAYGAIN_*`, `ISRC`, `BARCODE`).
- **Защита структуры «Folder-as-Album Lock»:** алгоритм анализирует папку целиком и запрещает дробить номерные альбомы на случайные сборники.

### 3. Исправление кодировки, AcoustID и обложки
- **Mojibake Fixer (CP1251 -> UTF-8 NFC):** автоматическое исправление битой кириллицы (Windows-1251, прочитанной как Latin-1) с защитой западноевропейских имен с умляутами (*Björk*, *Motörhead*) и принудительной нормализацией Unicode в NFC (критично для macOS).
- **AcoustID (`fpcalc` Chromaprint):** акустическое распознавание треков со стертыми или шаблонными тегами (`Track 01`), а также сверка длительности для защиты от путаницы со студийными и Live/Remix версиями.
- **Обложки высокого разрешения:** если в папке нет качественной обложки ($\ge 500\times500$), сервис загружает оригинал из Cover Art Archive или Apple Music (**iTunes Search API в разрешении 3000x3000bb.jpg**) и атомарно сохраняет `cover.jpg`.

### 4. Каскад поиска LRC (LRC Tournament по 4 базам)
При запросе запускается параллельный конкурентный опрос (Fan-Out на горутинах) по 4 источникам:
1. **LRCLIB API** — открытая международная база синхронов.
2. **Яндекс Музыка API** — главный источник на русскую сцену (поддержка HMAC-SHA256 подписи и OAuth-токена с Плюсом).
3. **NetEase Cloud Music (163.com)** — азиатская база, идеальна для редких релизов, OST и электроники.
4. **Genius API / Scraper** — текстовый эталон для рэпа, рока и андеграунда.

- **Таблица `provider_cache`:** все сырые ответы сохраняются в SQLite, позволяя в UI переключаться между вариантами текста без повторных сетевых вызовов.
- **Защита от сбоев:** индивидуальные Rate Limiters, Smart Retry (экспоненциальный бэкап + Jitter) и Circuit Breaker (отключение сбоящего провайдера на 3 минуты).

### 5. AI-валидация и Облачное Караоке (Groq Whisper + Gemini 2.5 Flash)
- **AI-Консенсус (Gemini 2.5 Flash):** очистка текстов от встроенных переводов (китайские строки в NetEase), транслита, структурных пометок (`[Куплет 1]`, `[Припев x2]`) и слияние точных таймкодов с эталонной орфографией.
- **Двухэтапная генерация караоке:**
  1. *Аудио -> Groq (`whisper-large-v3-turbo`):* аудиофайл на лету в оперативной памяти сжимается через `ffmpeg` в легкий моно-Opus (16 kHz, 32 kbps, ~1 МБ) и отправляется в Groq API с параметром `timestamp_granularities=["word", "segment"]`. За 1–2 секунды формируются точные акустические таймкоды.
  2. *Мердж -> Gemini 2.5 Flash:* полученные таймкоды объединяются с эталонным текстом, заменяя оговорки распознавания на 100% правильные строки с миллисекундной привязкой.
- **Атомарная запись:** итоговый проверенный синхронизированный текст сохраняется в `poisq.db` и записывается рядом с треком как `<filename>.lrc` (`.tmp` -> `os.Rename`).

### 6. Защищенный пул API-ключей (AES-256-GCM + LRU)
- Ключи шифруются алгоритмом **AES-256-GCM** мастер-ключом сервиса. В веб-интерфейсе отображается только маска (`AIza••••••cret`).
- **LRU-ротация:** нагрузка равномерно распределяется по всем активным ключам.
- **Обработка 429 Too Many Requests:** перевод ключа в cooldown на **65 секунд** с мгновенным переключением на следующий.
- **Исчерпание дневной квоты (RESOURCE_EXHAUSTED):** перевод в статус `exhausted_daily` до сброса квоты в полночь по PST (~11:00 МСК).
- **Ошибки авторизации (400/401/403):** перевод в статус `invalid` с уведомлением в UI.
- При исчерпании всех ключей очередь становится на безопасную паузу без падений.

## 🏛 Двухпортовая Архитектура

```
[ Клиенты (Feishin, Symfonium, Web) ]           [ Браузер администратора ]
                 │                                            │
                 ▼                                            ▼
      Публичный порт :4534                         Внутренний порт :4535
   (Только Умный Поиск Proxy)                     (Admin UI & AI-комбайн)
                 │                                            │
                 ├─────────────────────────┐                  │
                 ▼                         ▼                  ▼
       [ Navidrome (:4533) ]       [ Медиатека: /music (rw) ] ◄───┤
                 │                         ▲                      │
                 └─────────────────────────┴──────────────────────┘
                         (Navidrome нативно читает
                          .lrc, cover.jpg и теги)
```

1. **Публичный порт `:4534` (`LISTEN_ADDR`)**:
   - Перехватывает поисковые запросы (`/rest/search*`, `/api/*`), исправляет раскладку/опечатки и объединяет результаты (Fan-out).
   - Все остальные вызовы (включая стриминг и отдачу текстов Navidrome) прозрачно проксируются.
   - Админские функции и запись файлов на этом порту физически отсутствуют.
2. **Внутренний порт `:4535` (`ADMIN_LISTEN_ADDR`)**:
   - Открывает SPA-панель управления со встроенным React/Vite фронтендом (`//go:embed`).
   - Привязывается к `127.0.0.1` или внутренней VPN-сети.
   - Защищен HTTP-middleware от CSRF и DNS Rebinding.

## 🚀 Быстрый старт (Docker Compose)

### 1. `docker-compose.yml`

```yaml
services:
  # Официальный музыкальный сервер Navidrome
  navidrome:
    image: deluan/navidrome:latest
    container_name: navidrome
    restart: unless-stopped
    environment:
      ND_SCANSCHEDULE: "15m"
      ND_LOGLEVEL: "info"
      ND_SESSIONTIMEOUT: "24h"
      ND_BASEURL: ""
    volumes:
      - /path/to/your/music:/music:ro
      - navidrome_data:/data
    ports:
      - "4533:4533"

  # Умный поиск (:4534) + AI-комбайн и панель управления (:4535)
  poisq:
    image: ghcr.io/f5go/poisq:latest
    container_name: poisq
    restart: unless-stopped
    depends_on:
      - navidrome
    ports:
      # Публичный порт — умный поиск и Subsonic-прокси
      - "4534:4534"
      # Внутренний порт админки — доступ только с хоста / SSH-туннеля / VPN
      - "127.0.0.1:4535:4535"
    environment:
      LISTEN_ADDR: ":4534"
      ADMIN_LISTEN_ADDR: ":4535"
      NAVIDROME_URL: "http://navidrome:4533"
      NAVIDROME_DB_PATH: "/data/navidrome.db"
      POISQ_DB_PATH: "/data/poisq.db"
      MUSIC_PATH: "/music"
      POISQ_SECRET_KEY: "придумайте_секретный_ключ_для_шифрования_api_keys"
      SYNC_INTERVAL: "2m"
      ENRICH_SQLITE_FULLTEXT: "true"
      LOG_LEVEL: "info"
    volumes:
      - navidrome_data:/data
      - /path/to/your/music:/music:rw

volumes:
  navidrome_data:
```

### 2. Запуск контейнеров

```bash
docker compose up -d
```

### 3. Доступ к сервисам

- **Музыкальные плееры (Feishin, Symfonium, Amperfy, Web):**
  - Адрес сервера: `http://<IP_ИЛИ_ДОМЕН>:4534`
  - Логин и пароль: учетные данные Navidrome.
- **Панель управления poisq Studio:**
  - Откройте в браузере: `http://127.0.0.1:4535` (или через SSH-туннель `ssh -L 4535:127.0.0.1:4535 user@server`).

## 🖥 Панель управления poisq Studio (:4535)

Интерфейс собран в темной теме macOS / Linear UI и состоит из 4 разделов:

1. **Дашборд здоровья медиатеки (Health Check):**
   - Количество треков и папок альбомов.
   - Детектор отсутствующих и низкокачественных обложек ($< 500\times500$).
   - Счетчик файлов с битой кодировкой CP1251.
   - Покрытие текстами (отсутствуют / Plain / Synced LRC / AI-Verified).
   - Мониторинг очереди задач с кнопкой паузы воркера.
2. **Staging-экран рефакторинга:**
   - Таблица предложений от MusicBrainz, AcoustID и Mojibake Fixer с фильтрацией статусов.
   - Сравнение «Текущие данные (Было)» $\leftrightarrow$ «Предложение (Станет)».
   - Кнопки **[Применить]**, **[Игнорировать]** и **[↩ Откатить (Undo)]**.
3. **Менеджер LRC & AI-Караоке:**
   - Список треков с быстрым поиском и фильтром по статусу текста.
   - Переключение между вариантами из кэша провайдеров (`provider_cache`) в один клик.
   - Сдвиг таймкодов на $\pm 100$ и $\pm 500$ мс.
   - Кнопки запуска пайплайнов: *«Опросить базы»*, *«AI-Консенсус (Gemini 2.5)»*, *«Сгенерировать Караоке (Whisper + Gemini)»*.
   - Кнопка *«Сохранить в БД + записать .lrc»* для атомарного сохранения на диск рядом с аудиофайлом.
4. **Управление пулом API-ключей:**
   - Добавление ключей для Gemini, Groq, AcoustID, Яндекс Музыки и Genius.
   - Таблица ротации с живыми счетчиками Cooldown (обратный отсчет в секундах) и отображением дневных лимитов до 11:00 МСК.

## 🔑 Chrome-расширение для токена Яндекс Музыки

В репозитории есть готовое расширение для браузеров Chrome/Brave/Яндекс Браузер:
[`chrome-extension/`](./chrome-extension/)

Оно позволяет в один клик авторизоваться и получить OAuth-токен Яндекс Музыки с Плюсом для полнотекстового доступа и HMAC-подписи запросов к базе синхронов. Токен автоматически копируется в буфер обмена и может быть добавлен в пул ключей через панель `:4535`.

## ⚙️ Переменные окружения

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `LISTEN_ADDR` | `:4534` | Публичный адрес Subsonic-прокси (только умный поиск) |
| `ADMIN_LISTEN_ADDR` | `:4535` | Внутренний адрес панели управления и AI-комбайна |
| `NAVIDROME_URL` | `http://navidrome:4533` | URL вышестоящего инстанса Navidrome |
| `NAVIDROME_DB_PATH` | `/data/navidrome.db` | Путь к SQLite базе Navidrome |
| `POISQ_DB_PATH` | `/data/poisq.db` | Путь к собственной SQLite базе poisq.db |
| `MUSIC_PATH` | `/music` | Корневая директория медиатеки (монтируется `:rw`) |
| `POISQ_SECRET_KEY` | *(автогенерация)* | Секретный мастер-ключ для шифрования API-ключей (AES-256-GCM) |
| `SYNC_INTERVAL` | `2m` | Интервал фоновой синхронизации словаря и треков |
| `ENRICH_SQLITE_FULLTEXT`| `true` | Фоновое безопасное обогащение поиска в `navidrome.db` |
| `LOG_LEVEL` | `info` | Уровень логирования (`debug`, `info`, `warn`) |
| `ENABLE_DEBUG_API` | `false` | Включение диагностических эндпоинтов `/_smart/*` на порту :4534 |
