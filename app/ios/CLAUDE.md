# poisq iOS — правила проекта

## Интерфейс
- **Всегда стандартные системные средства**: системные шрифты (Dynamic Type, `.font(.title3)` и т. п., без своих гарнитур), системные анимации и переходы (`withAnimation { }` по умолчанию, `.smooth`, `.snappy`, `.spring` из SwiftUI, `navigationTransition(.zoom)`, `sheet`/`fullScreenCover`, `symbolEffect`, `contentTransition`), системные компоненты и материалы (Liquid Glass: `.glass`, `.glassProminent`, `.ultraThinMaterial`), SF Symbols, системные цвета и акцент.
- Свои кривые, длительности и самописные переходы — только если системный вариант не решает задачу, и с комментарием, почему.
- Жесты — через систему: прокрутка, свайпы списка, закрытие экрана — штатные. Самописный жест добавляем, только когда штатного нет.
- Для любого нового экрана сначала смотрим, как это делает Apple Music / Музыка / системные приложения iOS 26, и повторяем поведение.

## Локализация
- Интерфейс на русском и английском. Каждая новая строка сразу попадает в `Poisq/Localizable.xcstrings` с русским переводом. Английский — ключ.

## Совместимость
- Приложение работает с любым Subsonic-сервером. Улучшения через прокси poisq (расширение OpenSubsonic `poisq`) — только как надстройка: без него всё продолжает работать на стандартном API.
- Не копируем чужой код. Чужие приложения — только как ориентир по поведению.

## Сборка и проверка
- Проект собирается через XcodeGen: `xcodegen generate`, затем `xcodebuild -project Poisq.xcodeproj -scheme Poisq -destination 'id=<UDID симулятора>' build`.
- Тесты пакета: `cd PoisqKit && swift test`.
- Изменения интерфейса проверяем в симуляторе: после правки смотрим экран, а не только собираем.
