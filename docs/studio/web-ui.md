# poisq Studio (:4535)

**poisq Studio** (`internal/admin`) — встроенная в Go-бинарник (`//go:embed ui/*`) одностраничная веб-панель управления фонотекой. Интерфейс построен без внешних фреймворков на дизайн-системе **«Мастеринг»** (плоская монохромная палитра, светлая и тёмная темы, типографика `IBM Plex Sans` / `IBM Plex Mono`).

## Навигация и SPA-маршруты

Маршрутизация выполняется на клиенте через `history.pushState`; сервер отдаёт `index.html` для всех путей без расширения (кроме `/api/*`) с запретом кэширования динамических ресурсов.

| Раздел | URL | Возможности |
|---|---|---|
| **Медиатека** | `/library` | Сводка здоровья каталога (`/api/v1/health`), умный поиск по библиотеке (`internal/search/library_match.go`: омоглифы, транслит, опечатки), три режима просмотра (**Все треки**, **Исполнители**, **Альбомы**), фильтры (`all`, `synced`, `plain`, `none`, `mojibake`, `no_cover`). |
| **Тексты** | `/lyrics`, `/lyrics/<trackId>` | Сайдбар треков, HTML5-аудиоплеер с поддержкой `Range`, синхронизированный караоке-телесуфлер, запуск поиска текста (`tournament`) и генерации таймингов (`whisper_karaoke`), удаление `.lrc`, **визуальный редактор таймингов** и **сырой редактор `.lrc`**. |
| **Очередь задач** | `/lyrics/queue` *(редирект с `/jobs`)* | Автообновление раз в `2.5s`, раскрываемая карточка задачи с визуализацией этапов конвейера и живой консолью логов воркера, пауза/возобновление/повтор (`resume` или полный `restart` с очисткой кэша Whisper)/удаление. |
| **Биографии** | `/biographies` | Поиск артистов по `navidrome.db`, просмотр автоматической биографии и статуса фоновой задачи (9 стадий), форма ручного описания на русском (с опциональным URL источника), возврат к автоматическому, пересборка одного артиста и глобальный сброс кэша с сохранением ручных описаний. |
| **Исправления** | `/fixes` | Безопасный Staging-буфер: diff только изменённых полей тегов (`mojibake`, `musicbrainz`, `artist_canonical`, `manual`), side-by-side сравнение обложек «Было / Станет» с полноэкранным Lightbox, галерея альтернативных кандидатов (iTunes / Cover Art Archive), кнопка **«Уточнить альбом через AI»**, запуск аудита, массовое применение, отклонение и **Undo**. |
| **Настройки** | `/settings/keys`, `/settings/navidrome`, `/settings/cast`, `/settings/service` | Разделы управления ключами, интеграциями и обслуживанием базы. |

## Карточка трека (Drawer)

Клик по строке трека в `/library` открывает выдвижную панель деталей:
- метаданные, путь файла, разрешение обложки, превью текста;
- быстрый запуск поиска текста, AI-караоке, аудита конкретного трека и удаления `.lrc`;
- встроенная форма ручного редактирования тегов (`POST /api/v1/tracks/tags`), которая проходит через `StagingService.ApplyManualEdit` — правку можно откатить через Undo.

## Визуальный редактор таймингов (`timeline-editor.js`)

Открывается кнопкой **«Редактор таймингов»** в разделе `/lyrics/<trackId>`:

- **Волна громкости**: сервер декодирует аудио через `ffmpeg` в моно 8 кГц (`GET /api/v1/tracks/waveform`) и отдаёт 100 пар `min/max` в секунду с дисковым кэшем в `<TempDir>/poisq-waveforms/`. Рендер выполняется на HTML5 `<canvas>` с учётом DPR и `requestAnimationFrame`.
- **Индикация уверенности**: строки с оценкой `poisq-aligner` уровня `low` (красный) и `medium` (янтарный) подсвечиваются в списке и на волне; доступен счётчик проблемных строк и кнопка **«Следующая неуверенная»**.
- **Точная правка и горячие клавиши**:
  - перетаскивание меток мышью (с соблюдением порядка и минимального зазора `0.01s`);
  - сдвиг стрелками `←`/`→` на `±0.1s` (с `Shift` — `±0.01s`; внутри текстового поля строки — `Alt + ←/→`);
  - горизонтальная прокрутка колесом мыши, масштабирование `Ctrl/Cmd + колесо` или логарифмическим слайдером (до `800 px/s`);
  - кнопка **«▶ с метки»** запускает воспроизведение за `2s` до выбранной строки;
  - стек **Undo / Redo** до 200 шагов (`Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`) и предупреждение о несохранённых правках.
- При сохранении (`POST /api/v1/lyrics/save`) файл `.lrc` атомарно перезаписывается рядом с аудио, флаги неуверенности с отредактированных строк снимаются, а пары «было → стало» сохраняются в таблицу `lrc_corrections`.

## Разделы настроек (`/settings/*`)

1. **`/settings/keys` — Ключи API**: добавление, просмотр статуса (`active`, `cooldown`, `exhausted_daily`, `invalid`, `decrypt_error`), счётчиков успехов/ошибок и удаление ключей `groq`, `yandex` и `tavily`. Поле ввода использует маскированный `type="text"`, чтобы браузерные менеджеры паролей не перехватывали токены.
2. **`/settings/navidrome` — Служебный аккаунт Navidrome**: учётная запись без прав администратора, проверяемая через `/rest/ping` и шифруемая в `keypool` (провайдер `navidrome`). Используется как запасной источник стриминга аудио (если файла нет в локальной точке монтирования) и подгрузки обложек/фото артистов.
3. **`/settings/cast` — Music Assistant**: URL сервера, долгосрочный токен, выбор файлового провайдера (`filesystem*`) и чекбоксы колонок, доступных приложениям.
4. **`/settings/service` — Обслуживание**:
   - пауза/возобновление фонового воркера текстов;
   - ручной запуск синхронизации с `navidrome.db`;
   - полный сброс `poisq.db` (`POST /api/v1/db/reset`, по умолчанию сохраняет API-ключи и сразу перезапускает синхронизацию из Navidrome).
