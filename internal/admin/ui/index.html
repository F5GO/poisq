Secure Transport

Приложение poisq шифрует весь трафик до Studio, и CDN не видит логины, запросы и музыку. Устройство подключается сканированием QR в форме входа приложения. QR не содержит секретов, но показывайте его только своим пользователям.

Проверка...
Адрес, по которому приложение доступно из интернета через CDN. Только https, без пути.

Устройства

Устройства, вошедшие через Secure Transport. Отзыв сразу завершает сессии устройства; для повторного входа нужен пароль. Смена пароля в Navidrome отзывает все устройства пользователя.
